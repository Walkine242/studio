# Preview AquaSpeed Project

Follow these steps to run the Next.js development server and preview the application.

## Steps

1. **Verify Environment**
   Ensure Node.js v20+ is installed and dependencies have been installed (`npm install`).

2. **Start Dev Server**
   Run the development server using Turbopack:
   ```bash
   npm run dev
   ```

3. **Open Preview**
   Once the server starts, open [http://localhost:3000](http://localhost:3000) in your browser.
