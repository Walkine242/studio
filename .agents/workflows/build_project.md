# Build AquaSpeed Project

Follow these steps to install dependencies and compile the Next.js application.

## Steps

1. **Verify Node.js Version**
   Ensure Node.js v20+ is installed:
   ```bash
   node --version
   ```

2. **Install Dependencies**
   Install all package dependencies:
   ```bash
   npm install
   ```

3. **Typecheck**
   Run TypeScript validation to catch any compilation issues:
   ```bash
   npm run typecheck
   ```

4. **Build**
   Build the Next.js production bundle:
   ```bash
   npm run build
   ```
