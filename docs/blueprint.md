# **App Name**: AquaSpeed

## Core Features:

- Race Timer: Start, stop, and record swim times with lap tracking.
- Personal Bests: Automatically track and display personal best times for each stroke and distance.
- Technique Analysis Tool: Upload a video, and use AI to receive feedback on the swimmer's technique. The feedback is presented as an ordered list, to make it actionable.
- Workout Generator: Generate workouts tailored to the swimmer's skill level and goals. The tool may ask about experience, distance, current training plan (if any), target distance and stroke (if any).
- Stroke Rate Counter: Calculate and display the swimmer's stroke rate in real-time.
- Goal Setting: Allow users to set goals and track progress.

## Style Guidelines:

- Primary color: Deep Blue (#3498db) to evoke the feeling of water and speed.
- Background color: Light blue (#e7f5ff) to give a sense of spaciousness and lightness.
- Accent color: Vibrant orange (#e67e22) for CTAs and important timing data.
- Body and headline font: 'Inter' for a modern and readable interface.
- Use minimalist, water-themed icons to represent different strokes and features.
- Clean and spacious layout with clear data presentation for easy readability while swimming.
- Subtle, fluid transitions to provide a dynamic and engaging user experience.
